## SSH / PTY 补充

同型号／固件上的管理权限实测另包含：

- 官方 Dropbear 2026.94 源码的 ARM32 静态构建，密码与 PAM 认证编译关闭。
- 专用客户端公钥成功认证为 UID 0；错误密钥和密码认证被拒绝。
- LAN 地址／接口绑定，无 IPv6 SSH 监听；外部 IPv4／IPv6 TCP 22 探测均未连接成功。
- 最初非交互命令成功但 PTY 分配失败；私有 devpts 适配后，在保持 stdin 打开的真实终端中进入 shell、输入命令、验证 `test -t 0`、按 Ctrl+C 中断前台任务、正常退出。
- 修复继承的信号掩码；新会话不再屏蔽 SIGINT／SIGPIPE。
- 停止仅 SSH 服务、退出相关终端并卸载私有 PTY 后，下一次连接能按需恢复服务和交互终端。没有为此重新启动整台路由器。

公开补丁对应上述实测的两处源代码改动。公开部署包生成器和启动模板将地址／网段参数化，不包含现场设置。自动测试和交叉编译只证明工具及源码构建边界，不代替读者自己的安装、WAN 隔离或重启验证。
